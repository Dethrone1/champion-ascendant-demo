How it's built

A small data product built like a real one. The scoring formulas live in Python and are the single source of truth. The website runs a JavaScript port that tests hold to the Python, every published score is recomputed on every commit, and the formulas are judged against real outcomes, including the ones that made them look worse.

From record to page

One direction of flow. Data is worked in spreadsheets, scored in Python, and the browser reads tables generated from the Python, so the site can't carry a hand-copied second version of any rule.

Tested against the right target

The DWCS score is meant to describe who gets invited to the Contender Series. Early versions were checked against who won a UFC contract instead, and that made win streak look like the strongest variable. Against invites it's worse than a coin flip. Rebuilding around the right target moved the whole formula from 0.628 to 0.686.

AUC measures how well a score ranks fighters who were invited above fighters who weren't. 0.5 is a coin flip, 1.0 is perfect.

Practices

The habits that keep a one-person project honest.

One source of truth

Python decides every score. The browser's lookup tables are generated from it, never typed in, and a test fails if they fall out of date.

Versioned formulas

Every published score carries its formula version. No version bump while testing; a new version ships only when it's final. The DWCS v2.7.1 column was frozen before Season 10 and has never been edited.

Pre-registration

A score only counts as a call if it was dated and public before the outcome. Everything else is logged as tracking. Clean calls so far: zero, and the site says so.

No silent edits

Every change to a published number goes on the corrections log with a date, including the calculator bug that shipped on 24 Oct.

No leakage

Signees are scored on their record the day they signed. The ONE formula is never tuned on how fighters did after joining.

Real counts only

No rounded-up or padded numbers. If a title win can't be confirmed in fight records, it scores zero.

Run it yourself

# clone and run the site
git clone https://github.com/Dethrone1/champion-ascendant-demo
cd champion-ascendant-demo
pip install -r requirements.txt
python app.py                        # http://localhost:5000

# run the tests
python scoring/test_both_systems.py
python scoring/test_parity.py        # needs Node.js

Champion Ascendant

A benchmark, not a prediction. ASCENT describes how closely a fighter matches the record profile of real signings and invites. It doesn't say who will get signed.
